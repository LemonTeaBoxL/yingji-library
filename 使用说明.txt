映迹 · 作品与素材资料库 0.4.14

启动
先退出旧版，再运行“映迹资料库-0.4.14.exe”或“启动映迹”快捷方式。Windows 64 位便携程序，无需开发工具；首次解包需要一些时间。

0.4.14 更新（2026-11-25）
1. 个人资料库的瀑布流改为接近底部自动分批追加条目，直到当前筛选结果全部显示，无需点击显示更多。适用于全部条目、标记条目、收藏、个人条目及本地素材。
2. 保留排序、多选与已有卡片的位置；切换页面丢弃旧的追加回调，打开详情时暂停底下的追加，关闭后恢复。列表和普通网格的原有按钮保持原样。

0.4.13 更新（2026-11-25）
1. 修复源网页作品内部含有嵌套菜单时，旧解析器提前结束作品行、遗漏未入库作品的问题；作品顺序、评分、季度筛选与分页继续沿用源站。
2. 更新作品浏览缓存格式，自动绕过旧格式的不完整浏览页，首次重新读取源网页；保留个人记录、封面与关联素材，之后继续使用新的完整缓存。

0.4.12 更新（2026-11-25）
1. 修复季度或有评分筛选后连续翻过大量空页，界面长期显示正在载入的问题。连续三页没有新增符合条件的作品时暂停自动翻页，可点击继续载入；保留源网页顺序，不将空筛选页误判为最后一页。
2. 载入时显示当前读取页码及源网页总页数，并可暂停等待；请求超时后释放载入状态，显示可操作的重试按钮。连接与正文读取均有超时保护。
3. 翻页失败保留已有作品与已完成页码，重试同一失败页；过期或已暂停请求的迟到响应不再覆盖当前搜索。切换页面仍保留发现页的浏览位置。

0.4.11 更新（2026-11-24）
1. 标记条目提供“全部 / 看过 / 待看 / 在看”四个标签，与状态筛选双向联动。“已观看”统一为“看过”；整部作品取消重点和未标记状态选项，旧的整部重点归入在看，单集重点标注保留。
2. 修复在看未计入标记条目的问题；个人库的列表、侧栏及顶部数量统一统计有效标记。默认标记不显示在个人库，旧版未标记记录仅隐藏，升级时不静默删除它的文件。
3. 右键看过/待看/在看恢复默认标记前先弹出警告。确认会从个人库移除此作品，并删除个人评分、观后感、单集记录、独占关联素材副本及对应缓存，不能撤销；取消则保持不变。电脑源文件和其他条目仍引用的文件保留。不自动删除已有备份或服务器历史快照。
4. 新增“Chrome 登录”：在 Chrome 加载随程序提供的“映迹 · Bangumi 登录同步”扩展后，粘贴映迹的一次性连接码，点击同步，即可复用所选 Bangumi 网站的会话。仅读取所选站点的 Cookie，经本机接口写入映迹会话；不解密 Chrome 数据库，不读取其他站点或密码。源站可能仍要求重新登录或验证。
5. Chrome 登录面板有安装和同步步骤，扩展文件夹会复制到用户资料目录，程序升级后不会因临时解包目录消失而失效。AI 接口仍为只读。

作品与个人记录
发现作品提供 Bangumi 动画、动画电影、真人影视和游戏；TMDB 需要个人免费 API 密钥，可在偏好设置中加密保存。
年份从 1977 年起，提供季度、地区、形式、源站评分等筛选。作品范围以源站收录为准；季度、有评分筛选作用于当前已载入作品；发现页顺序由网站拉取方式决定。
未入库作品显示“标记”，首次点下为看过，再点切换待看。首次收藏默认整部与已知单集看过，之后可自行调整。
整部作品和单集均可评分、评论。单集进度条仅在网页资料页显示，可拖动或加减，与逐集记录同步。
详情封面下显示 Bangumi 完整信息栏，以源站实际提供为准。网页资料和我的空间分开。
个人条目页面只显示自己手动创建的作品，自建分类可重复使用。

复制入库
导入文件或拖入图片、视频及数据库文件，程序复制到所选资料库内。源文件不会被搬走或修改。
读取整个外部文件夹与持续外部索引功能已经取消；请批量选择具体文件。
往条目素材栏拖入文件，会复制到该条目的 materials 子目录；普通导入的独立文件放在 imports 目录。
我的空间支持原比例缩略图、放大镜悬浮预览、框选、Ctrl 多选、Shift 连选、Ctrl+A 全选、Delete/Backspace 移除。完成选择或 Esc 清除高光。
移除关联素材前确认，仅删除不再被引用的库内副本，电脑源文件保留。
“带有素材的条目”只检查素材栏关联，不把源站封面计为素材。搜索时关闭筛选条件开关也会暂时绕过此条件。
旧索引首次转为副本需要一次复制时间；无法读取的旧文件会保留不可用记录，可重新导入。程序之后不再连接和扫描旧文件夹。

资料库文件夹
在偏好设置 → 资料库位置与互通选择文件夹。支持中文路径。迁移复制当前资料与缓存后重启；旧位置保留。
library.json：UTF-8 明文用户记录与快速索引，后台线程原子写入。
library-format.json：开放格式说明。
entries/<id>/entry.json：单个作品、评分、单集记录、观后感与素材列表；可用时含完整源站单集资料。
entries/<id>/materials/：条目素材副本；entry.json 内素材路径相对于条目目录。
imports/：普通导入的图片、视频与数据库副本。
entries/<id>/cover.jpg：已下载的封面副本。
catalog-cache、offline-works、covers、thumbnails：作品资料与预览缓存。
preferences.json、appearance、runtime：外观、背景、搜索记忆与运行时数据。
backups：曾经迁移/下载服务器资料产生的备份。彻底清空时一并删除。
系统原配置目录仅需 library-location.json 位置指引。托管路径相对保存，可整体搬走；读取使用内存索引，只更新变化的条目文件。

清空与源文件保护
偏好设置的一键清空需再次确认，将清空本机条目、个人记录、全部素材副本和旧备份，并删除作品资料缓存。此操作不再自动备份，无法撤销。
清空保留外观设置、服务器连接和程序运行文件。不会删除所选资料库外的源文件，不会自动删除远程 WebDAV 快照。
程序检查受控目录的真实位置；目录链接或被识别为原始源文件的内容会使清空停止，避免误删。
要保留资料，请在清空前自行导出索引并复制整个资料库文件夹。

服务器
设置中填写 WebDAV 目录地址、账号和密码/应用密码，验证后手动上传或下载。服务器目录需已创建，账号需读写权限。
同步索引、条目资料、单集资料和已入库文件，保留本地副本离线使用；临时浏览缓存、运行时和密钥不上传。
密码使用系统保护加密保存在本机，不回显。下载前确认并备份；文件通过 SHA-256 校验后安装。
其他设备更新后会阻止直接覆盖；先下载再编辑上传。当前是手动整库同步，不自动合并多设备改动。服务器需支持 ETag 条件写入。

视频与数据库
本地副本可播放、截帧、调整片段时长并导出 MP4；默认中等压缩，导出生成新文件。
SQLite 以只读分页方式浏览；JSON、JSONL、CSV、TSV 可导入和搜索。操作的数据库是库内副本，源文件保留。

外观与窗口
支持高分屏缩放、多种颜色主题、列表/封面/瀑布流与紧凑/舒适/大封面密度。排序位于布局按钮旁。
详情旁齿轮可即时调节主题、磨砂、白色底色、边缘折射与放大；偏好设置可重启程序。
液态材质使用 rdev/liquid-glass-react 原版组件与 Electron 适配层。应用内背景支持折射/磨砂；窗外桌面由 Windows acrylic 处理，不截取桌面画面，不承诺像素一致的物理焦散。
可关闭动效，窗口按钮可放左/中/右，窗口可拖动缩放。

AI 接口
本版本保留仅本机只读的 AI 接口，可搜索条目、读取详情与浏览数据库。连接信息只交给受信任工具，不支持 AI 写入。

映迹 · Bangumi 登录同步

首次安装：
1. 在映迹里点击“Chrome 登录”→“打开扩展文件夹”。
2. Chrome 地址栏打开 chrome://extensions，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择映迹打开的文件夹。

同步登录：
1. 在 Chrome 正常登录 bangumi.tv、bgm.tv 或 chii.in 中的一个网站。
2. 映迹的 Chrome 登录面板中点击“复制连接码”。
3. 点击 Chrome 工具栏中的本扩展，选择刚才已登录的网站，粘贴连接码，点击“同步登录到映迹”。
4. 映迹会检查源站是否能正常读取。连接码十分钟有效且只能成功使用一次，失败可重新生成。

范围：
只在你点击同步时读取所选 Bangumi 网站的 Cookie，通过 Chrome 官方扩展接口取得；不读取其他网站，不读取密码，不解密 Chrome 数据库。
Cookie 只传到本机 127.0.0.1 的映迹程序，不保存到扩展存储或明文文件；映迹将它写入自己的浏览器会话。
Chrome 中登录过期时，需要在 Chrome 重新登录后再次同步。网站仍可能要求验证，程序不会自动处理验证码或绕过网站限制。

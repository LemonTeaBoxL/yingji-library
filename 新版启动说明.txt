映迹资料库 0.4.15

先退出旧版，再双击 映迹资料库-0.4.15.exe 或 启动映迹.lnk。

0.4.15 更新（2026-11-25）
1. 全部条目仅展示作品记录；图片、视频等素材仍在本地素材页查看。
2. 个人条目的封面支持右键“自定义封面…”及恢复默认封面；图片复制到条目文件夹，不影响源文件，也不会混入关联素材列表。
3. Bangumi 发现作品新增书籍、音乐栏目，支持相应源网页、搜索与年份筛选；书籍和音乐不套用动画形式筛选。
4. 新建个人条目增加音乐、其它，小说统一更名为书籍；已有小说分类及筛选记忆自动兼容，保留自定义分类和个人记录。

0.4.14 更新（2026-11-25）
1. 个人资料库的瀑布流改为接近底部自动分批追加条目，直到当前筛选结果全部显示，无需点击显示更多。适用于全部条目、标记条目、收藏、个人条目及本地素材。
2. 保留排序、多选与已有卡片的位置；切换页面丢弃旧的追加回调，打开详情时暂停底下的追加，关闭后恢复。列表和普通网格的原有按钮保持原样。

0.4.13 更新（2026-11-25）
1. 修复源网页作品内部含有嵌套菜单时，旧解析器提前结束作品行、遗漏未入库作品的问题；作品顺序、评分、季度筛选与分页继续沿用源站。
2. 更新作品浏览缓存格式，自动绕过旧格式的不完整浏览页，首次重新读取源网页；保留个人记录、封面与关联素材，之后继续使用新的完整缓存。

0.4.12 更新（2026-11-25）
1. 修复季度或有评分筛选后连续翻过大量空页，界面长期显示正在载入的问题。连续三页没有新增符合条件的作品时暂停自动翻页，可点击继续载入；保留源网页顺序，不将空筛选页误判为最后一页。
2. 载入时显示当前读取页码及源网页总页数，并可暂停等待；请求超时后释放载入状态，显示可操作的重试按钮。连接与正文读取均有超时保护。
3. 翻页失败保留已有作品与已完成页码，重试同一失败页；过期或已暂停请求的迟到响应不再覆盖当前搜索。切换页面仍保留发现页的浏览位置。

0.4.11 更新（2026-11-24）
1. 标记条目提供“全部 / 看过 / 待看 / 在看”四个标签，与状态筛选双向联动。“已观看”统一为“看过”；整部作品取消重点和未标记状态选项，旧的整部重点归入在看，单集重点标注保留。
2. 修复在看未计入标记条目的问题；个人库的列表、侧栏及顶部数量统一统计有效标记。默认标记不显示在个人库，旧版未标记记录仅隐藏，升级时不静默删除它的文件。
3. 右键看过/待看/在看恢复默认标记前先弹出警告。确认会从个人库移除此作品，并删除个人评分、观后感、单集记录、独占关联素材副本及对应缓存，不能撤销；取消则保持不变。电脑源文件和其他条目仍引用的文件保留。不自动删除已有备份或服务器历史快照。
4. 新增“Chrome 登录”：在 Chrome 加载随程序提供的“映迹 · Bangumi 登录同步”扩展后，粘贴映迹的一次性连接码，点击同步，即可复用所选 Bangumi 网站的会话。仅读取所选站点的 Cookie，经本机接口写入映迹会话；不解密 Chrome 数据库，不读取其他站点或密码。源站可能仍要求重新登录或验证。
5. Chrome 登录面板有安装和同步步骤，扩展文件夹会复制到用户资料目录，程序升级后不会因临时解包目录消失而失效。AI 接口仍为只读。

0.4.10 更新（2026-11-24）
1. 在个人资料库、作品世界与设置之间切换时，发现页保留原来的作品卡片、已加载页数、搜索筛选、显示方式和滚动位置；不因返回页面自动刷新。手动刷新、重试或主动更改搜索筛选才重新读取。后台请求完成时也不会错误重置页面。
2. 登录窗口的图片右键增加“复制图片地址”“复制图片”“在小窗口查看原图”；输入框支持复制、粘贴等常用菜单。原图预览优先使用当前已经加载的图像，保留原始分辨率，不另发验证码请求。遇到跨域图片无法预览时仍可复制图片或地址。
3. 登录窗口与作品读取共用程序自己的浏览器会话，关闭登录窗口前写入网站允许持久保存的 Cookie。外部 Chrome/Edge 的 Cookie 不会自动读取或导入。

0.4.9 更新（2026-11-24）
1. 右键“看过 / 待看”可恢复为“标记”；清除该作品的观看进度，保留收藏、评分、观后感、单集评论与素材。再次点击“标记”即标为看过。
2. 发现作品的两个排序菜单合为“网站拉取方式”：排名、热度、收藏、日期、名称。切换从第一页重新读取 Bangumi 源网页，连续翻页保留源站顺序；个人资料库原有排序独立保留。
3. Bangumi 部分浏览方式、筛选组合需要登录。失败时可点击“登录 Bangumi”，在源站窗口自行登录，关闭窗口后自动重试。登录状态仅保存在本机选定资料目录的浏览器数据中，程序不读取密码。
4. 关键词搜索使用公开搜索接口，只支持排名和收藏人数排序，其他三项暂不可用；清空关键词后恢复五项。季度和有评分筛选作用于已载入页面，不改变源站分页。

0.4.8 更新（2026-11-24）
1. 取消文件来源、读取文件夹、外部文件夹连接及重新扫描入口；顶部按钮改为刷新当前页面。
2. 拖入或选择的图片、视频及数据库文件全部复制入库；不再登记外部文件夹。拖入文件夹会提示选择具体文件。旧版仍可读取的外部索引在首次打开时转为副本，原文件保留。
3. 全部条目、标记条目（看过/待看）、我的收藏、个人条目增加“带有素材的条目”筛选。各页面分别记忆；本地素材页此选项显示已关联到作品的素材。
4. 清空个人资料库现在彻底删除本机条目、素材副本、旧备份、封面、缩略图及作品缓存；不再自动保留备份。操作前警告，无法撤销。程序不删除电脑源文件，也不会自动删除 WebDAV 服务器上的历史快照。
5. 清空先等导入与缓存任务结束，并关闭只读数据库连接。删除目标限定在资料库的受控子目录，检查真实路径与目录链接；遇到原始文件或外部目录链接会停止清空。
